# Credit Card Churn Prediction

## 🎯 Objective
A machine learning solution that predicts whether a credit card account is likely to churn, and 
uncovers the key drivers behind customer attrition — helping banks move from reactive to 
proactive retention.

## 📌 Business Context
Customer churn is a major challenge in the banking industry, driving up acquisition costs and 
eroding revenue. This project builds a model to flag high-risk customers early, enabling 
targeted retention strategies before they leave.

## 🔍 Approach
Built end-to-end following the CRISP-DM lifecycle:
- **Data preparation** — cleaning, EDA, and leakage-safe feature engineering (no direct 
  identifiers used in modeling)
- **Modeling** — trained and compared multiple classifiers, with all experiments tracked in a 
  trials log
- **Evaluation** — performance assessed using metrics suited to imbalanced churn data 
  (e.g. precision, recall, ROC-AUC)
- **Business insights** — translated model outputs into clear, actionable findings for 
  stakeholders

## 🏁 Outcome
- Clean, prepared dataset
- Trained and evaluated model(s)
- Business + technical presentation of results
- Documented assumptions, decisions, and experiment trials
